1. 起步：接下来该做什么

这是我的厨房菜谱控制器设想，我想要你教我一下现在接下来该做什么。我要接 Arduino 并控制网页菜谱，设想使用三个按钮，分别设置在厨房的下方。点击按钮时先检测舵机是否已经转向按钮方位，如果没有先执行转向；如果已经在按钮方位，那就执行让菜谱翻页，双击则是让菜谱返回上一页，长按播放这一页的菜谱操作。

现有的程序已经实现了这套逻辑：没朝向时任何操作只转向；已朝向时单击下一页、双击上一页、长按朗读。接下来是一步步接硬件，每步只加一样东西：

  1. 只插 Uno、上传固件，串口监视器（115200）里应看到 READY / STATION 1 COUNTER / ARRIVED 1。
  2. 接三个按钮（D2/D3/D4 到 GND，不需要电阻），测试单击、双击、长按的输出。
  3. 接 SG90 空载测试舵机，用 ANGLE 0 25 这样的命令校准角度。
  4. 关掉串口监视器，用 Chrome 或 Edge 打开网页，点「连接 Arduino」。
  5. 装进厨房：换大舵机并配独立 5–6V 电源（必须和 Uno 共地），按钮换成脚踏开关。

普通舵机不能回报实际角度，「是否已朝向」是程序记住的位置；如果要真正检测，需要带反馈的舵机或位置传感器。

2. 按钮没反应

我已经接好线了，但是按钮没反应

Claude 直接读了串口：Uno 一重启就输出 READY，固件正常；但按按钮的 25 秒里没有任何输出，说明问题在接线。排查方法：

  • 先用一根杜邦线把 D3 和 GND 碰一下，能触发就说明问题在按钮本身。
  • 四脚小按键同侧的两个脚内部是通的，要用对角线的两个脚，并且跨在面包板中间的凹槽上。
  • 确认插的是数字 2/3/4，不是 A2/A3/A4 或 TX/RX。

开关分正负极吗

普通开关不分。要注意的是：三脚微动开关接 C 和 NO；带 VCC/GND/OUT 的按钮模块分极性，而且逻辑是反的，需要改代码。

（贴出串口日志：按钮按下后依次出现 STATION 0 SINK、STATION 1 COUNTER、STATION 2 STOVE）

按钮通了，三个站点都能转向。下一步继续按同一个按钮测试 NEXT / PREV / READ。日志里有一处值得注意：

ARRIVED 2
STATREADY

STAT 打了一半就变成 READY，说明 Uno 在转向时重启了，很可能是舵机从 Uno 的 5V 取电、电流不够。可以在舵机电源上并 470–1000µF 电容，最好用独立电源并共地。

3. 舵机不转

舵机没工作

日志里的 ARRIVED 只是程序按时间算的，不代表舵机真的转了。检查：信号线（橙/黄）接 D9，红线接 5V，棕线接 GND；插头别插反；用外部电源时要和 Uno 共地。然后用 IDE 自带的 文件 → 示例 → Servo → Sweep 单独测舵机。

传了，舵机不动

Sweep 也不动，说明问题在硬件本身。最快的判断方法是用手轻拧摇臂：很松说明没电或没信号，查三根线；很紧、拧不动说明有电但带不动，换外部电源。

好了。舵机转了，硬件没问题。怎么链接软件

  1. 把 recipe_controller.ino 重新传回去（板子里现在是 Sweep）。
  2. 关掉串口监视器：一个串口同一时间只能被一个程序占用。
  3. 用 Edge 或 Chrome 打开 recipe_display.html（Safari 不支持网页串口）。
  4. 点「连接 Arduino」，选 USB Serial 端口，再选一道菜。

4. 连接网页

一直显示未连接，同时我还想要你把菜谱改成英文版

未连接的原因：Arduino IDE 的串口监视器一直占着端口，网页打不开它，而原来的网页失败了也不提示。网页改成了：

  • 连接失败时用红字说明原因和解决办法（比如「端口被占用，请关闭串口监视器」）。
  • 授权过一次之后，打开网页或插拔 USB 时自动重连。

英文版：原来的 HowToCook 只有中文，所以菜谱来源换成了免费的英文菜谱库 TheMealDB（14 个分类，可搜索）。界面、站点名（Sink / Counter / Stove）和朗读语音都换成了英文。原来的中文页面另存了一份。

5. 朗读控制和步骤长度

我希望如果正在阅读的时候点击按钮，可以暂停阅读，如果再 hold 的话从头开始阅读。同时，每一步不要写的太长，视觉清晰一点

状态单击双击长按
正在朗读停止朗读停止朗读从头重读
没在朗读下一步上一步从头朗读
  • 朗读时页面上显示「🔊 Reading · tap to stop」。停止后再单击一次才翻页，踩停朗读不会顺带翻页。
  • 每页只放一个短动作（约 110 个字符以内），时间和温度高亮，比如 10 mins、180C。

6. 页面重叠、每步配料、中英切换、图片

食材准备和操作提示会有重叠，同时你可以在每一步标注需要的食材

  • 配料很多时内容不再盖住顶部和底部，超过 10 种配料时改成小字三栏。
  • 每一步下面用小标签列出这一步用到的配料和用量（例如 1 tsp Chilli Powder），长按朗读时也会读出来。配料是靠比对步骤文字找出来的，偶尔会多标或漏标。

可以加切换中英文的按钮吗

顶部加了「中文 / English」按钮，一键切换界面、菜谱来源（中文用 HowToCook，英文用 TheMealDB）和朗读语音。两种语言各自记住看到哪道菜、哪一步。两边是不同的菜谱库，不是同一道菜的翻译。

首页的图片显示不全，其次步骤中如果有图片的话可以添加

图片移到文字右边，按原比例完整显示；窄屏时排到文字下面。中文菜谱里有步骤图的会显示在对应步骤旁边，没有成品图时首页用最后一张步骤图。英文菜谱库每道菜只有一张成品图。
