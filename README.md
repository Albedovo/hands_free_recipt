# Hands-Free Recipe 原型：接线与使用说明

**直接打开：<https://albedovo.github.io/hands_free_recipt/>**（手机竖屏也可以用；连接 Arduino 需要电脑上的 Chrome / Edge）

## 文件

| 文件 | 用途 |
|---|---|
| `recipe_controller/recipe_controller.ino` | Arduino Uno 固件：三个脚踏按钮 + 舵机转向 |
| `index.html` | GitHub Pages 首页，自动跳到 `recipe_display.html` |
| `recipe_display.html` | 菜谱页（电脑 / 手机竖屏）：3 道手写的详细菜谱（中英文）、厨房位置提示、厨房布局设置、朗读，通过 USB 串口接收踏板操作 |
| `docs/Uno_AI开发过程与代码说明.md` | 开发过程、AI 使用说明和代码讲解 |
| `docs/conversation_uno.html` | 和 Claude 的对话整理（Uno 阶段） |
| `docs/project_overview.html` | 英文项目介绍和流程图 |

## 交互逻辑

三个按钮按位置固定在台面下方的踢脚板：**左 = D4，中 = D3，右 = D2**，用脚触发。每个位置对应哪个厨房区域（水槽 / 切配区 / 灶台），在网页的「厨房设置」里调区域顺序就行，接线和固件都不用改。

| 屏幕状态 | 操作 | 结果 |
|---|---|---|
| 屏幕没朝向这个按钮 | 任何操作 | 只把屏幕转过来，不翻页 |
| 屏幕已朝向这个按钮 | 单击 | 下一步 |
| | 双击 | 上一步 |
| | 长按（约 0.7 秒） | 朗读这一步 |

转向后 0.35 秒内的连按会被忽略，防止"转过来"的那一脚顺带翻了页。网页上的「锁定转向」打开后，屏幕停在原地不动，三个按钮都直接控制菜谱，适合站在一处看的时候用。

## 需要的材料

- Arduino Uno + USB 线
- 3 个按钮：先用普通按键开关测试；装到地面上换成脚踏开关、压力垫或微动开关（两根线的常开开关都可以）
- 舵机
  - 空载测试：SG90
  - 要转动手机或平板：MG996R 这类金属齿舵机，配 **独立 5–6V、2A 以上的电源**
- 可选：3 个 LED + 3 个 220Ω 电阻，用来显示屏幕朝向哪一站
- 可选：470–1000µF 电解电容（并在舵机电源上，减少抖动和 Arduino 复位）
- 面包板、杜邦线

## 接线

```
                       Arduino Uno
                  ┌──────────────────┐
   右边按钮 ──────┤ D2               │
   中间按钮 ──────┤ D3               │
   左边按钮 ──────┤ D4               │
   (按钮另一端全部接 GND)            │
                  │                  │
   LED 左 ────220Ω┤ D5  (可选)       │
   LED 中 ────220Ω┤ D6  (可选)       │
   LED 右 ────220Ω┤ D7  (可选)       │
   (LED 负极接 GND)                  │
                  │                  │
   舵机信号(橙/黄)┤ D9               │
                  │              GND ├──┬── 舵机 GND(棕/黑)
                  └──────────────────┘  └── 外部电源 GND（必须共地）
   舵机电源(红) ── 外部 5–6V 电源正极
```

| 元件 | 引脚 | 接到 |
|---|---|---|
| 左边按钮 | 一端 / 另一端 | D4 / GND |
| 中间按钮 | 一端 / 另一端 | D3 / GND |
| 右边按钮 | 一端 / 另一端 | D2 / GND |
| 舵机 信号（橙或黄） | | D9 |
| 舵机 电源（红） | | 外部 5–6V 正极（只用 SG90 空载测试时可以接 Uno 的 5V） |
| 舵机 地（棕或黑） | | 外部电源负极，**同时连到 Uno 的 GND** |
| LED（可选） | 正极经 220Ω / 负极 | 左 D5、中 D6、右 D7 / GND |

要点：

- 按钮不需要外接电阻，代码用了内部上拉 `INPUT_PULLUP`，按下读到 LOW。
- 外部电源和 Uno 必须共地，否则舵机信号无效或乱转。
- 带负载的舵机不要从 Uno 的 5V 取电：电流不够会导致 Uno 反复重启、串口断开。
- 按钮线拉到地面会很长（1–3 米）。如果出现误触发，在每个按钮两端并一个 100nF 电容；或者用双绞线。

## 使用步骤

1. **上传固件**：用 Arduino IDE 打开 `recipe_controller/recipe_controller.ino`，开发板选 Arduino Uno，选好端口，上传。Servo 库是 IDE 自带的。
2. **先不接硬件测试**：打开串口监视器（115200，换行符选 "Newline"），按按钮应该看到 `NEXT 1`、`STATION 2 STOVE` 这类输出。也可以手动输入 `GOTO 0` 看舵机是否转动。
3. **关闭串口监视器**（同一个串口只能被一个程序占用）。
4. **用 Chrome 或 Edge 打开 `recipe_display.html`**（直接双击即可）。Safari 和 Firefox 不支持 Web Serial。
5. 点「连接 Arduino」，选择 Uno 的串口。连接时 Uno 会自动重启一下，舵机回到中间。
6. 点顶部的菜名选择菜谱（目前 3 道：西红柿炒鸡蛋、蒜蓉西兰花、酸辣土豆丝，不需要联网）。
7. 点「⚙ 厨房设置」设置厨房布局：目前支持长条形（一字形）台面，可以调整 洗菜区 / 切配区（切菜和备菜在同一块台面）/ 灶台 三个区域从左到右的顺序，每个区域自动使用它下面的那个踏板（左 D4 / 中 D3 / 右 D2）。如果踩左边的踏板，网页上「🧍 你在这」却出现在右边，在同一个设置窗口里切换「踏板左右对调」（默认打开）。只影响网页显示，不改变舵机转向。

## 页面怎么读

- 顶部的厨房条按设置的顺序画出四个区域：**「🧍 你在这」** 是你最后踩的踏板所在的位置；**彩色高亮 +「去这里」** 是这一步要去的区域，中间的箭头告诉你往左还是往右走几格。
- 下面的提示条直接写出要做什么：「→ 走到 🔥 灶台 · 往右 1 格 · 到了踩右边的踏板」，到了以后变成绿色「✓ 你在灶台」。
- 脚踏没法滚动页面，所以**一页只放一个动作**，页面永远不需要滚动（内容多时字号会自动缩小到能装下）。每一步拆成几页：第一页带“用到什么”，最后一页带“做好的样子”和“注意”。右上角的小圆点表示这一步做到第几个动作，底部一行预告下一页要做什么。
- 需要等的时间（比如“煮 60 秒”“泡 10 分钟”）直接写在页面上并高亮，网页不做计时。
- 手机上没有串口：可以点厨房条上的区域模拟“走到这里”，用底部按钮翻页。

没有硬件时，可以用键盘测试网页：→ 下一步，← 上一步，空格朗读，1/2/3 模拟走到某个踏板，L 锁定，A 自动朗读，/ 选菜。

## 校准舵机角度

代码里默认 左 / 中 / 右 三个站点的角度是 `{30, 90, 150}`。如果踩左边按钮屏幕却转向右边，说明舵机装的方向反了，把 30 和 150 对调即可。现场调整方法：

1. 先关掉网页的串口连接，在 Arduino IDE 的串口监视器里发送 `ANGLE 0 25` 这样的命令。舵机会立即转到新角度，反复试出合适的值。
2. 记下三个角度，填回 `.ino` 里的 `stationAngle[]`，重新上传。

## 可以调的参数（`.ino` 顶部）

| 参数 | 默认 | 作用 |
|---|---|---|
| `DOUBLE_GAP_MS` | 350 | 双击判定窗口。脚踩比手点慢，误判成两次单击时调大到 400–450 |
| `LONG_PRESS_MS` | 700 | 长按阈值 |
| `SERVO_STEP_MS` | 12 | 每转 1° 的间隔。调大转得更慢更稳，120° 约 1.4 秒 |
| `START_STATION` | 1 | 开机朝向的站点 |

## 串口协议

Arduino → 电脑：`READY`、`STATION <i> <名字>`、`ARRIVED <i>`、`NEXT <i>`、`PREV <i>`、`READ <i>`、`LOCK <0|1>`

电脑 → Arduino：`GOTO <i>`、`LOCK`、`UNLOCK`、`ANGLE <i> <度数>`、`STATUS`

`<i>` 是站点编号，按位置从左到右：0 左（D4）、1 中（D3）、2 右（D2）。后面换成人脸跟踪时，网页只需要按人脸位置发 `GOTO`，或扩展一个直接发角度的命令。

## 已知限制

- 普通舵机不能读回实际角度。"屏幕是否朝向这里" 是程序记录的目标站点；如果有人用手扳动了支架，程序不会知道。
- 网页串口只在电脑的 Chrome / Edge 上可用。手机可以直接打开页面看菜谱（竖屏已适配），但要接 Arduino 仍需电脑；也可以用屏幕镜像把电脑画面投到手机上。
- 厨房布局目前只做了长条形；L 形、双排、岛台在设置里先占位。
- 朗读用的是浏览器自带的中文语音；Windows 和 macOS 一般都自带中文语音，Linux 上可能需要另装。
